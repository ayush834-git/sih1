## 3. CLAIMS WE MUST NOT MAKE (Strictly Prohibited)

The following claims are mathematically, empirically, or methodologically invalid. If a judge asks, we must explicitly disclaim them.

| Prohibited Claim | Why It Exceeds Evidence / Why It Is Invalid | Correct Replacement Formulation |
|------------------|---------------------------------------------|---------------------------------|
| ❌ **“AR(5) outperforms logistic regression overall.”** | False. Static LR has a higher F1 score (0.4000 vs 0.3575) and lower FPR (33.2% vs 66.6%) than AR(5) trajectory. AR(5) only wins on Recall (77.97% vs 57.43%). There is an operational trade-off, not overall superiority. | "AR(5) achieves higher detection recall than static LR, but operates at a higher false positive rate." |
| ❌ **“The system provides 10 seconds of guaranteed advance warning / gives operators 10 seconds to stop attacks.”** | Prediction horizon $\neq$ actionable warning. A classifier with high FPR can fire early by chance. Furthermore, real SOC triage involves human latency that cannot be modeled as a pure 10s credit. | "The model forecasts 10 to 30 seconds ahead; in controlled replays, this triggered predictive alerts 10 seconds before static threshold crossings." |
| ❌ **“Future Security Risk $R(t+h)$ is an attack probability / infiltration probability.”** | Mathematically incorrect. $R(t+h)$ is an uncalibrated heuristic composite index $[0, 1]$ combining velocity, anomaly severity, and trust. It does not integrate to 1 and is not a probability distribution. | "Future Security Risk $R(t+h)$ is a normalized operational priority score $[0, 1]$." (Calibrated probability is emitted separately by the progression model). |
| ❌ **“The system achieves 0% false positives / zero false alarms.”** | Overclaim. In controlled 32-window test progression replays zero false alarms were observed, but in uncurated chronological benchmark test data, the calibrated model produces an FPR of 0.60% (8 false alarms) and AR(5) produces an FPR of 66.64%. | "The calibrated progression model achieves a 0.60% false positive rate on held-out chronological benchmark data." |
| ❌ **“We proved generalization to unseen attack families / this proves directional momentum transfers / proven generalization.”** | The unseen DDoS evaluation evaluated 40 transitions ($N=40$). While directional accuracy was positive (64.6% non-zero DA), magnitude MAE shifted to 1.88 (nearly 2x IQR). 40 samples cannot 'prove' universal cross-family generalization. | "We observed limited cross-family directional transfer on an unseen DDoS-HOIC evaluation slice (N=40), while magnitude calibration degraded under the observed distribution shift. This is preliminary evidence of transfer, not proof of broad unseen-attack generalization." |
| ❌ **“We built a deep learning world model / generative neural world model.”** | We did not build a Dreamer, PlaNet, Transformer, LSTM, or GNN. The dynamics core is a linear Autoregressive model of order 5 ($p=5$) over discrete state deltas. | "We implemented an interpretable autoregressive temporal world-model formulation for discrete network states." |
| ❌ **“The system automatically blocks attacks / prevents breaches autonomously.”** | Destructive autonomous blocking without human confirmation risks enterprise outages (denial-of-service via defensive automation). High blast-radius actions explicitly require human authorization (`requires_human=True`). | "The system recommends reversible mitigation actions gated by human authorization for high blast-radius interventions." |
| ❌ **“The system predicts stealthy payload-level zero-days.”** | The system operates on macroscopic transport and packet telemetry (rates, port diversity, flag tallies, TTL variance). Encrypted or low-volume application logic exploits do not produce macroscopic transport anomalies. | "The system forecasts macroscopic transport-layer behavioral transitions; application-layer payload exploits are outside the NetFlow observability boundary." |
| ❌ **“Validated in live enterprise / critical infrastructure networks / endorsed by NCIIPC / fully validated / national-level proven.”** | False and unethical. Experiments were conducted on CSE-CIC-IDS2018 datasets and localhost Windows loopback (`\Device\NPF_Loopback`). No production enterprise network was tapped. | "The system is architected for enterprise/CII decision-support, with verification conducted in controlled simulation and localhost capture." |
| ❌ **“Real-time packet-by-packet attack prediction.”** | The model does not predict per-packet. It operates on 10-second discrete window aggregations. | "The system performs windowed 10-second network-state transition forecasting." |
